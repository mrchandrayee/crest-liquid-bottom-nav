A fluid liquid-effect animated bottom navigation bar with smooth morphing transitions. Pure HTML, CSS & JavaScript.

---

## ✨ Features

- 🌊 Liquid morphing active indicator
- 📍 5-tab bottom navigation
- ✨ Smooth SVG path animation
- 📱 Mobile-first design
- ⚡ Zero dependencies
